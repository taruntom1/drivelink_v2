DriveLink apt repository

Signed packages for Ubuntu 24.04 (noble) and 26.04 (resolute), amd64 and arm64: drivelink-agent, drivelink-cli and, on 26.04, the GUI drivelink. It holds the latest release; older versions stay on the GitHub release pages.

Add the repository

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/drivelink-archive-keyring.asc https://taruntom1.github.io/drivelink_v2/drivelink-archive-keyring.asc
gpg --show-keys /etc/apt/keyrings/drivelink-archive-keyring.asc
. /etc/os-release
printf 'Types: deb\nURIs: https://taruntom1.github.io/drivelink_v2/\nSuites: %s\nComponents: main\nSigned-By: /etc/apt/keyrings/drivelink-archive-keyring.asc\n' \
  "$VERSION_CODENAME" | sudo tee /etc/apt/sources.list.d/drivelink.sources
sudo apt update
sudo apt install drivelink-agent drivelink-cli

The key's fingerprint must be:

0B7A BAC1 B5A9 95FB 3512 E068 6964 AFD8 333B B3D6

Check it against the fingerprint in the DriveLink repository (packaging/apt/FINGERPRINT), not only this page. An upgrade (sudo apt upgrade) never restarts a running agent: run sudo systemctl restart drivelink-agent when the robot is safe to stop.
