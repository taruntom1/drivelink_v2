Downloads

Find the app for your computer and the firmware that runs on the ESP32-S3. Check your operating system and architecture before you choose a download.

DriveLink 0.2.1 release notes

Desktop app

Your computer Download
Windows 11, 64-bit Intel or AMD Download the Windows installer
Ubuntu 26.04, 64-bit Intel or AMD (amd64) Download the amd64 package
Ubuntu 26.04, 64-bit ARM (arm64) Download the arm64 package

On Windows, run the installer. You should see DriveLink in the Start menu when setup finishes. On Ubuntu, install from apt to get the app and its dependencies. The Debian packages (.deb files) above are also available for manual installation.

ESP32-S3 firmware

Download the firmware zip contains the firmware and instructions for first flash. Use Flash in the browser to install it on a new board or reset an existing one.

Linux and ROS 2 packages

Install from apt for the DriveLink agent (the service on the Pi) and the ROS 2 packages. Apt verifies the packages against the signed repository. The release page lists the individual package files.

Verify a download

  1. Download SHA256SUMS and open that file in a text editor. Find the line for your download. GitHub displays some Linux package filenames with a dot before ubuntu. The checksum list uses the original filename, with a tilde.
  2. Open a terminal in your Downloads folder and compute the SHA-256 checksum, a string that identifies the exact file contents. Replace FILE with the downloaded filename.
Get-FileHash -Algorithm SHA256 'FILE'

sha256sum 'FILE'
  1. Compare the 64 characters you see with the ones on the matching line in SHA256SUMS. Letter case can differ. If any character differs, discard that download and download it again.
