# Registry

The MSG_TYPEs and stream channel ranges of the wire protocol. The tables are generated from `protocol/defs/registry.yaml` by `tools/gen/gen.py`; edit the YAML and regenerate, never the tables. How the definitions work is in [definitions.md](definitions.md), and the frame and the MSG_TYPE classes are in [framing.md](framing.md).

A legacy entry is the old protocol of a manager that a later overhaul step ports. The step removes the entry with the manager. The time ping (0x02 / 0x42) joins in F8; the legacy IMU response holds 0x42 until F6 removes the IMU manager.

## MSG_TYPEs

| Value | Name | Class | Direction | Legacy | Use |
|---|---|---|---|---|---|
| 0x01 | `core_command` | command | host to ESP |  | Core command (family, op). Not used until F3. |
| 0x02 | `time_request` | command | host to ESP |  | Host time ping, answered directly in RX. |
| 0x03 | `disarm` | command | host to ESP |  | DISARM fast path, handled in the RX callback and never queued. |
| 0x23 | `diag_query` | command | host to ESP |  | diag query: GetInfo, GetEntries, Clear. |
| 0x41 | `core_response` | response | ESP to host |  | Answer to a core command. |
| 0x42 | `time_response` | response | ESP to host |  | Time reply with monotonic RX and TX-submission timestamps. |
| 0x63 | `diag_query_response` | response | ESP to host |  | Answer to a diag query. |
| 0x80 | `status_stream` | stream | ESP to host |  | System status stream, also the heartbeat. |
| 0xC0 | `diag_event` | event | ESP to host |  | diag events: Record, CounterDelta, Cleared, Boot. |
| 0xC1 | `core_event` | event | ESP to host |  | Core events: capture done, test signal done, layout applied, OTA state, arm state change. |

## Stream channel ranges

| Range | Channels | Direction | Usable | Use |
|---|---|---|---|---|
| `sub_groups` | 0x81-0x9F | ESP to host | 31 (0x81-0x9F) | Subscription groups 0-30. |
| `cmd_groups` | 0xA0-0xBF | host to ESP | 32 (0xA0-0xBF) | Command groups 0-31. |

The system type id is 0x00; the built-in loop type id is 0x05.
