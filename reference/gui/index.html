Desktop app screens

Use this page to find a task in the DriveLink app. You need the installed desktop app. Open Connect first to start a session.

Screen Use it to
Connect Open a serial device or connect through an agent.
Device Check firmware, arm state, and device identity. Find Device settings (change a capacity limit), Firmware update and, in remote mode, Clients and lease.
Layout Add loops and instances and set their parameters and wiring. Review pending edits and save them.
Monitor Plot live signals, make a capture, or find Manual command.
Tune Run step tests, compare traces, and identify the response.
Settings Change app preferences such as appearance and whether to browse for agents.
About Find the app version, release information, and notices.

The app’s IMU calibration panel opens from the IMU instance in Layout. Use Arming and faults to interpret the status and diagnostic information.
