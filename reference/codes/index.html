Status, fault, and diagnostic codes

Use this page when the app’s diagnostics or a ROS log shows a code. A request reports a result and can add a detail. Diagnostic entries describe events or conditions. For a fault, fix the cause before acknowledging it. See Arm is refused for common actions.

Device status

Arm state What you can expect
Disarmed Motor output is disabled. You can read the device and prepare a command.
Armed The device can act on fresh motion commands.
Fault Motor output has been disabled. Clear the cause and acknowledge the fault before arming.

The status stream also identifies why the device last disarmed. An explicit disarm can replace an earlier reason. Use the diagnostic record and the ROS log to find the original trigger.

Last disarm code Meaning
0 The device booted.
1 A client or operator requested disarm.
2 The command watchdog expired.
3 A fault disarmed the device.
4 A device loop stalled.
5 The device shut down.

Diagnostic codes

Find both the source and the code. Different sources can use the same number. A record describes an event. A counter reports how often something occurred. The Clears column tells you whether the diagnostic can report that its condition has cleared.

Source Code Name Severity Kind Clears arg0 arg1 Description
system (0x01) 0x0001 ManagerStartFailed (retired) error record no manager id (1 motor_manager, retired in F5b; 2 time_sync, 3 imu retired in F6) unused A manager failed to start. It is left out, and the rest of the firmware keeps running.
system (0x01) 0x0002 PeriodicSyncStartFailed (retired) error record no unused unused time_sync started, but its periodic sync task did not. esp_err gives the reason.
uart_comm (0x02) 0x0001 CrcError warning counter no - - A frame candidate with a valid header was rejected for a CRC16 mismatch.
uart_comm (0x02) 0x0002 PartialFrame warning counter no - - A partial frame was dropped because the sender stopped mid-frame.
uart_comm (0x02) 0x0003 FrameOrParityError warning counter no - - The UART reported a framing or parity error.
uart_comm (0x02) 0x0004 RxOverflow warning counter no - - The RX hardware FIFO overflowed or the ring buffer was full.
uart_comm (0x02) 0x0005 LengthError warning counter no - - A frame candidate with a valid header CRC was rejected because LEN exceeded the maximum payload.
uart_comm (0x02) 0x0006 DiscardedBytes warning counter no - - Received bytes that were not part of any valid frame (counts bytes, not events).
uart_comm (0x02) 0x0007 HeaderCrcError warning counter no - - A frame candidate was rejected for a header CRC (HCRC) mismatch, before its payload was awaited. Also counts false preambles found while resyncing after noise.
diag (0x03) 0x0001 RecordDropped warning counter no - - A record or Cleared event was dropped because the diag record queue was full (or diag was not initialized yet).
diag (0x03) 0x0002 EventTxDropped warning counter no - - A diag query response could not be queued for UART transmission and was dropped.
diag (0x03) 0x0003 QueryDropped warning counter no - - A diag query was dropped because the reporter's query queue was full.
core (0x04) 0x0001 InitFailed error record no stage (1 registry, 2 loop task, 3 retired, 4 boot - Core::boot refused, which is a programming error in main) for stage 1, the index of the rejected module type; for stage 2, the loop id; else unused Core startup failed. Stage 2 leaves the named loop Failed and its modules DependencyMissing; other loops and the config link stay available. Other stages leave the core out; legacy managers keep running. esp_err gives the loop task error.
core (0x04) 0x0002 InstanceStartFailed error record no type id << 8 | instance id stage (the instance's own stage from fail() - controller.cascade_pid 1 missing or incompatible refs, 2 actuator already claimed - or a core stage - 0x100 create returned null, 0x101 start failed without a stage, 0x102 a bind was rejected, 0x103 a param, signal or input was left unbound) A module instance failed to start. It is left out, and the rest of the core keeps running. esp_err is the one passed to fail(), or 0.
core (0x04) 0x0003 TimerRestartFailed error record no loop instance id the period that failed, in us A loop's timer could not be restarted with a new rate. The rate change is rolled back and the param SET answers Fault. esp_err gives the reason.
core (0x04) 0x0004 SafeModeEntered error record no the crash counter (consecutive boots after a panic or a watchdog reset) unused The device booted in safe mode after 3 or more crash resets in a row. Every configured instance is offline and no instance was created; no loop task starts. Params and the layout can still be read and edited. Any reset that is not a crash, or EXIT_SAFE_MODE, ends it.
core (0x04) 0x0005 LayoutInvalid error record no type id << 8 | instance id the core Detail of the check that failed (UnknownType, LoopMismatch, BadLabel, LabelInUse, GpioNotAllowed, GpioConflict, BadRef, WiringCycle, Capacity, ...; numbered in registry.yaml from F3b) A layout entry loaded from NVS failed validation at boot and was left out. layout_invalid is set. Instances wired to it are left out too (core.DependencyMissing).
core (0x04) 0x0006 DependencyMissing error record no type id << 8 | instance id of the instance left out type id << 8 | instance id of the instance it is wired to, which is not running An instance was left out at boot because an instance it is wired to (a ref param) is invalid, failed to start or is itself missing a dependency. Its configuration is kept.
core (0x04) 0x0007 ConfigLoadFailed error record no the newest layout generation that passed its checks (0 when none did) cause (1 no layout blob passed its checks, 2 no generation had every instance blob) NVS holds a configuration but no complete generation of it could be loaded, so the device booted with the factory layout. config_loaded_from_nvs is false. Not reported on a blank NVS.
core (0x04) 0x0008 NvsWriteFailed error record no the namespace, type id << 8 | instance id (0xFFFF for the layout namespace core, 0xFFFE for the link namespace link) operation (1 write a blob, 2 erase a namespace) An NVS write or erase failed during SAVE, FACTORY_RESET or LINK_CONFIRM. A failed SAVE answers Fault and leaves the previous generation intact. esp_err gives the reason.
core (0x04) 0x000A LinkReverted error record no the link that was given up: baud rate / 100 << 16 | TX pin << 8 | RX pin why: 1 the trial ended unconfirmed (reported on the trial link, the device reboots); 2 the device reset before a trial was confirmed; 3 its UART failed to open; 4 the start of the trial could not be stored, so it did not run The device left a serial link for an older one. Causes 1 to 4 go back to the confirmed link; cause 3 on the confirmed link itself goes to the factory link. esp_err gives the reason for causes 3 and 4.
core (0x04) 0x0009 NvsInitFailed error record no what happened (1 the partition was full or from a newer NVS version, so it was erased and re-initialised and the stored configuration is lost; 2 NVS could not be initialised and nothing will be saved) unused Reported by main at boot. esp_err is the error that nvs_flash_init returned (stage 1) or the final error (stage 2).
motor_manager (0x10) 0x0001 InitFailed (retired) error record no stage that failed: 1 mutex, 2 config queue, 3 invalid config (UartComm invalid or max_motors 0), 4 configure callback, 5 setpoint callback, 6 update task, 7 control timer, 8 config task, 9 telemetry stream slot unused MotorManager failed to start. esp_err gives the reason. system.ManagerStartFailed follows.
motor_manager (0x10) 0x0002 MotorCreateFailed (retired) error record no motor id hardware stage that failed: 1 motor driver (DIR GPIO or MCPWM), 2 encoder (PCNT) CreateMotor passed validation, but the hardware could not be set up. ESP_ERR_NOT_FOUND means the MCPWM or PCNT pool is empty and the response is CAPACITY_REACHED. Anything else is answered with INTERNAL_ERROR.
motor_manager (0x10) 0x0003 TimerRestartFailed (retired) error record no requested control period (us) unused SET_TIMING could not restart the control timer at the new period. The old period stays in effect.
motor_manager (0x10) 0x0004 ControlTimerStalled (retired) warning record yes wait without a tick (ms) unused The control timer stopped waking the update task, so the control loop is not running. Detected by the config task. Cleared when the timer fires again or the manager stops.
motor_manager (0x10) 0x0005 ControlOverrun (retired) warning counter no - - Control ticks that were skipped (the update task ran late, or a configure command held the manager mutex).
motor_manager (0x10) 0x0006 SetpointBadFrame (retired) warning counter no - - A setpoint stream frame was dropped because its header or length was invalid.
motor_manager (0x10) 0x0007 SetpointRejected (retired) warning counter no - - A setpoint stream entry was dropped (unknown motor id, invalid kind, non-finite value, or a full mailbox).
motor_manager (0x10) 0x0008 ConfigQueueFull (retired) warning counter no - - A configure command was not applied because the config queue was full. It is answered with detail QueueFull.
motor_manager (0x10) 0x0009 ResponseTxDropped (retired) warning counter no - - A configure response could not be queued for UART transmission and was dropped. The command itself was still applied.
core (0x04) 0x0106 BadTimeRequest warning counter no - - A time ping was dropped because its exact length or independent protocol version was invalid.
time_sync (0x11) 0x0001 InitFailed (retired) error record no stage that failed: 1 UartComm invalid, 2 mutex, 3 response queue, 4 response callback unused TimeSync failed to start. esp_err gives the reason. system.ManagerStartFailed follows.
time_sync (0x11) 0x0002 SyncFailed (retired) warning record yes stage that failed: 1 request send, 2 no response before the timeout, 3 host returned an error status, 4 setting the clock host status byte (stage 3), else 0 A periodic time sync failed. Reported once per run of failures, and cleared on the next successful sync or when periodic sync stops. A round skipped because a manual sync was in progress is not reported.
time_sync (0x11) 0x0003 BadResponseFrame (retired) warning counter no - - A time sync response was dropped because it could not be decoded (bad length or version).
imu (0x12) 0x0001 InitFailed (retired) error record no stage that failed: 1 mutex, 2 invalid config (UartComm invalid, period bounds or operation mode), 3 BNO055 device, 4 default operation mode, 5 config queue, 6 configure callback, 7 config task, 8 stream task, 9 sampling timer, 10 stream slot unused The IMU manager failed to start. esp_err gives the reason. system.ManagerStartFailed follows.
imu (0x12) 0x0002 FallbackToMock (retired) warning record no I2C port BNO055 I2C address The BNO055 did not initialize, so the IMU streams synthesized mock data instead (fallback_to_mock_on_init_failure). esp_err gives the device error.
imu (0x12) 0x0003 ModeSwitchFailed (retired) error record no requested operation mode unused SetOperationMode could not write the new mode to the BNO055. A busy device (BUSY response) is not reported here.
imu (0x12) 0x0004 StreamReenableFailed (retired) error record no cause: 1 manager mutex busy, 2 sampling timer did not restart unused The stream stayed off after an operation-mode switch. Enable it again with SetStreamEnabled.
imu (0x12) 0x0005 CalibrationReadFailed (retired) error record no unused unused ReadCalibration failed on the BNO055 bus. A busy device (BUSY response) is not reported here.
imu (0x12) 0x0006 CalibrationApplyFailed (retired) error record no unused unused ApplyCalibration failed to write the offsets to the BNO055. A busy device (BUSY response) is not reported here.
imu (0x12) 0x0007 TimerRestartFailed (retired) error record no requested sample period (us) unused SetStreamTiming could not restart the sampling timer at the new period. The old period stays in effect.
imu (0x12) 0x0008 SamplerStalled (retired) warning record yes wait without a tick (ms) unused The stream is enabled, but the sampling timer stopped waking the stream task. A timeout across a timer restart (enable, SetStreamTiming) is not a stall. Cleared when it fires again, the stream is disabled, or the stream task stops.
imu (0x12) 0x0009 SampleLate (retired) warning counter no - - Sample periods that were missed because the stream task ran late.
imu (0x12) 0x000A DeviceBusy (retired) warning counter no - - Samples skipped because a configure operation held the BNO055.
imu (0x12) 0x000B ReadError (retired) warning counter no - - Samples that failed to read from the BNO055.
imu (0x12) 0x000C EncodeError (retired) warning counter no - - Samples that could not be encoded into a stream packet.
imu (0x12) 0x000D ConfigQueueFull (retired) warning counter no - - A configure command was not applied because the config queue was full. It is answered with detail QueueFull.
imu (0x12) 0x000E ResponseTxDropped (retired) warning counter no - - A configure response could not be queued for UART transmission and was dropped.

feedback_mock (0x71) 0x0001 InitFailed error record no stage (instance-specific below 0x100, core 0x100 create, 0x101 start, 0x102 bind, 0x103 unbound) unused The module instance failed to start.
actuator_pwm_dir (0x21) 0x0001 InitFailed error record no stage (1 a pin left unset, 2 driver setup failed - the DIR GPIO or MCPWM; esp_err ESP_ERR_NOT_FOUND when all six MCPWM operators are taken; core 0x100 create, 0x101 start, 0x102 bind, 0x103 unbound) unused The module instance failed to start. Reported in place of core.InstanceStartFailed; esp_err is the driver error, or -1.
feedback_quadrature (0x22) 0x0001 InitFailed error record no stage (1 a pin left unset, 2 driver setup failed - PCNT or the pull-up GPIO; esp_err ESP_ERR_NOT_FOUND when all four PCNT units are taken; core 0x100 create, 0x101 start, 0x102 bind, 0x103 unbound) unused The module instance failed to start. Reported in place of core.InstanceStartFailed; esp_err is the driver error, or -1.
imu_mock (0x72) 0x0001 InitFailed error record no stage (instance-specific below 0x100, core 0x100 create, 0x101 start, 0x102 bind, 0x103 unbound) unused The module instance failed to start.
core (0x04) 0x0100 CommandDropped warning counter no - - The core command queue was full.
core (0x04) 0x0101 ResponseDropped warning counter no - - A core reply could not be queued for transmission.
uart_comm (0x02) 0x0008 StreamSkipped warning counter no - - A stream write was skipped because its slot was busy.
core (0x04) 0x0102 LoopOverBudget warning counter no - - A loop tick took longer than its period; instance identifies the loop.
core (0x04) 0x0103 CommandFrameRejected warning counter no - - A command group frame was rejected (unconfigured group, version, epoch, length, invalid value or busy mailbox); no value was applied and it cannot feed the watchdog.
