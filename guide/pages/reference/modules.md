# Module types and parameters

Use these tables to look up a type shown in **Layout**. A type describes what an [instance]({{base}}concepts/modules/) can do. Parameters configure it. Signals report measurements and inputs accept commands. Compare the units and allowed range with your hardware before applying a setting. Types with `.mock` in their names are for virtual-device tests.

For `locked_while_armed` settings, disarm before editing. For `reboot_required` settings, [save and reboot]({{base}}concepts/saving/) before using the new value.
