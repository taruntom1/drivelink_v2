# Desktop app screens

Use this page to find a task in the DriveLink app. You need the [installed desktop app]({{base}}pc/install/). Open **Connect** first to start a session.

| Screen | Use it to |
| --- | --- |
| **Connect** | [Open a serial device]({{base}}pc/connect/) or [connect through an agent]({{base}}pi/connect/). |
| **Device** | Check firmware, arm state, and device identity. Find **Device settings** ([change a capacity limit]({{base}}pc/settings/)), **Firmware update** and, in remote mode, **Clients and lease**. |
| **Layout** | [Add loops and instances and set their parameters and wiring]({{base}}pc/layout/). Review pending edits and save them. |
| **Monitor** | [Plot live signals, make a capture, or find Manual command]({{base}}pc/monitor/). |
| **Tune** | [Run step tests, compare traces, and identify the response]({{base}}pc/tune/). |
| **Settings** | Change app preferences such as appearance and whether to browse for agents. |
| **About** | Find the app version, release information, and notices. |

The app’s [IMU calibration panel]({{base}}pc/imu/) opens from the IMU instance in **Layout**. Use [Arming and faults]({{base}}concepts/safety/) to interpret the status and diagnostic information.
